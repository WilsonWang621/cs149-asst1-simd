# Collaboration Rules

These rules apply to this directory and all its subdirectories.

1. Before every code modification, ask the user and obtain explicit approval before making changes.
2. Strictly follow the project requirements and guidelines in `README.md`. Read the relevant instructions before starting a task.
3. After writing or modifying code, explain what changed, the implementation approach and logic, and why that approach was chosen.
4. Keep responses concise and clear. Answer only what the user asks, without unsolicited elaboration or scope expansion.
5. Use English for code, comments, documentation, and other project file content. Use Chinese for conversation with the user.
